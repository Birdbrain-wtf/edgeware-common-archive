Speckle is a multi-chain browser extension for the Polkadot ecosystem, and we want to provide native and ongoing support for Edgeware within the app.

We are currently building support for the Polkadot Relay Chain, and we want to provide cross-compatible support for Edgeware. We are testing integration with the Edgeware testnet at the moment, but we our goal is to provide ongoing and updated support.

While the user will be able to add any substrate network to the extension, native support for Edgeware will enable us to also provide functionality and features that may be specific to the Edgeware chain itself. Further, we are creating a parachain and dapp discovery system, so the user will be able to discover, filter and select chains that they want to interact with upon account creation. This is a great step towards increasing user awareness and adoption.

We also aim to make the extension usable with the Commonwealth governance interface, so accounts created on Speckle can be used to create Web 3 identities. We want to make Speckle one of the premium ways to access Edgeware.
