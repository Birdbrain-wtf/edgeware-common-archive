The team at OnFinality is proud to announce that we have delivered and implemented public shared node services to the Edgeware community (as per [Treasury Proposal #16](https://commonwealth.im/edgeware/proposal/treasuryproposal/16-onfinality-public-nodes-for-edgeware)). OnFinality is the leading IaaS (infrastructure as a service) platform providing mission critical infrastructure to the Polkadot ecosystem. We now completely support Edgeware on our platform, allowing free community shared node API endpoints and one-click dedicated node deployments. 

There are three ways that the Edgeware community can access free high performance shared nodes on the OnFinality platform: 

## 1. Directly via the Public API Endpoint
Edgeware community users can quickly access OnFinality's public endpoint using the following two endpoints:

HTTPS: `https://edgeware.api.onfinality.io/public`

Websocket: `wss://edgeware.api.onfinality.io/public-ws`

## 2. Directly via their own Private API Endpoint
Edgeware community users can create their own account in OnFinality to receive their own private API endpoint. An advantage over the public API endpoint is that we provide insightful statistics and metrics to each API key holder about their requests. Free private API keys can be requested from [app.onfinality.io](https://app.onfinality.io) 

![Private Endpoint](https://miro.medium.com/max/1400/1*d8Nx6ygEtcf6B_5P667SHg.jpeg "Private Endpoint") 

## 3. Through Polkadot.js
You'll now see that [Polkadot.js](https://polkadot.js.org/apps/?rpc=wss://edgeware.api.onfinality.io/public-ws#/explorer) has OnFinality listed as a provider for Edgeware. Connect to us today! 

![PolkadotJS](https://miro.medium.com/max/1400/1*7WagbarGTJU26Y2_3EI8vw.png "PolkadotJS") 

## Bonus: Dedicated Nodes 
If the Edgeware community has needs above and beyond what our free API service providers, we also provide one-click dedicated node access for Edgeware that users can deploy from [app.onfinality.io](https://app.onfinality.io/)
