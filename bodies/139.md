At this point we're still waiting on a few major fixes to launch a stable Edgeware testnet.

**Online validator slashing issue**: We've observed a slashing issue where at times batches of 'im_online' heartbeats will not be registered by the chain. This causes large numbers of well-behaving validators to be slashed for being offline. This doesn't appear to have happened on Kusama CC2/PoS, so we think the problem will be resolved shortly, either by our forthcoming upgrade to the latest Substrate master, or by further debugging.

**Storage root mismatch issue**: There is a node crash that happens occasionally. The underlying cause is that the trie storage root may get out of sync. This happens infrequently enough that it's difficult to debug, but a tentative fix is in the works. In the interim, node operators should run node management software which monitors for the Edgeware process going down and restarts it when necessary.

The forthcoming testnet, which will probably be versioned 0.10, will provide the all-clear for mainnet launch ideally at the end of this month.

In the meantime, we're continuing to make improvements to the Commonwealth interface. Around the end of this month, we'll have a much user-friendlier interface for composing new discussions and comments, and a new and improved design for user profiles. Later this year we'll introduce integrations with other platforms like Github, Discord, Discourse, and Riot, so you can keep track of all the progress happening on Edgeware starting from one place.
