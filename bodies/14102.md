**Goal: **
Create legal entities tied to a crypto address using Edgeware

**Background: **
Being able to create a legal entity tied to a crypto address can be useful for new projects or for tax reasons. A 'Series LLC' is a type of LLC that can have hundreds of 'child LLCs'. Each Child LLC can be assigned its own owner. For this project, the 'Child LLC' is assigned an owner based on a crypto address, which is signified both by a legal contract as well as a crypto-token/NFT.

This proposal was originally submitted by Etherize, a LLC/DAO company that was disbanded soon after. Around that time, a very similar project called Kali was released, supporting Ethereum. The goal is now to expand upon Kali's platform to also support Edgeware.

**Requirements:**
Add in support for using Edgeware (Polkadot) to Kali's front end repository.

Legal contract should be generated and signed using the wallet. A token/NFT should be generated upon signing.

**Implementation:**

Fork the Kali front end.
A user should be able to select the Polkadot wallet when using the Kali front end.
If they do so, rather than create an Ethereum DAO, the process should be changed to only create a NFT on Edgeware. The name of the DAO/LLC should be included in the NFT details.
