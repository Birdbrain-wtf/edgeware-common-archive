Agreeing on community conduct standards is key for supporting strong collective action. Below is a proposal for Edgeware Community Guidelines. Let’s talk and make a version we can get some consensus on!

1. Be exceptionally kind.
2. Be respectful - but we should flesh out what this means.  
3. Freedom of speech is expected (but see rules #1 and 2). 
4. No illegal activity.
5. No harassment of any sort. 
6. No spam. Only contribute discussion and votes that you, as an individual, genuinely think offer value and are to the benefit of the community. 
7. If you’re offering criticism, be constructive.
8. Share the space, be inclusive. Try to be empathetic and allow everybody to get their voice in.  

I think it’s good to keep it fairly simple and focus on the principles behind the code of conduct rather than setting very strict rules. Do you agree? 

One place where this might not apply would be if the community decides we should have a clear dispute resolution system set in place. But perhaps that should be part of a different discussion. Would anybody be interested in working together to craft a mediation process proposal for Edgeware?
