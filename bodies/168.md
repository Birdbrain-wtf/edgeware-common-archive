I got the chance to ask [Attic Lab](https://atticlab.net/)'s team some questions about their Web3 Wave Three grant-winning project, a [Substrate VS Code Plugin](https://github.com/everstake/vscode-plugin-substrate). Here's what I learned! 
 
### Tell us about the Attic Lab Substrate VS Code Plugin.
 
Attic Lab, the team that brought you Everstake, just wrapped up their Web3 Foundation Wave Three grant project, a Substrate plugin for VS Code. As project manager Vitalii Parkhomenko describes it, the plugin is meant to be a “multifunctional tool for blockchain development.” The team is working to give developers a single space in which to create, test, and launch custom-designed blockchains. They’re focused on speed and convenience, leveraging the power behind Substrate and Visual Studio Code IDE. 
 
### What does the plugin do?
 
Their roadmap had a few pieces. First, they had to integrate the plugin into a sidebar with a control panel. The control panel allows developers to send transactions to the chain, as well as giving a view to logs and returned results from the executed transactions. The plugin also allows users to:
 
- Install a local Substrate node,
- setup a development chain,
- start/stop the development chain,
- clear the chain data (for restarting chain from genesis),
- manage accounts,
- send test extrinsics,
- and view output logs.
 
The plugin is specifically able to parse node configuration and recognize extrinsics types (transactions or inherents), as well as inputs, from a given chain. There is a user interface to easily list and send extrinsics, and the plugin also contains controls for deploying and calling smart-contracts in a current development chain. Extrinsics can also be verified by the plugin with checks for critical bugs. The team has worked on making the same functionalities available for the Atom editor. 

### Why is Attic Lab excited about Polkadot?

As Vit told me: “The short answer is 'because we love Substrate'.” More specifically, they’re looking forward to the amount of customization that the Substrate modules offer, and the speed of development available - which is in part possible because Substrate is so easy to learn. They’re very enthusiastic about Substrate and Polkadot, with goals to improve dev tools and offer as much value to the space as they can!
