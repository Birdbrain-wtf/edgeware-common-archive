Hi everyone! This is Raymond from the Commonwealth team.

We've spent the last couple of weeks upgrading the testnet to the latest version of Substrate. Unfortunately this resulted in some extended downtime. We're now back and don't expect this to happen again.

There are still a few bugs which will be fixed when we deploy the next testnet (V0.5.0). You will see some errors on the homepage in the meantime. Not all the governance features work perfectly yet. Those will be fixed well before mainnet launches.

In the meantime, our product team is shifting our main focus to discussions and user experience. We are:

- Re-designing the homepage, updating the layout, and adding features like likes/reactions to help surface the most interesting and relevant discussions.
- Simplifying how identities work.
- Expanding profile pages, to include more interesting information.
- Integrating `polkadot-js`, a Chrome/Firefox extension that will let anyone use the Commonwealth interface without ever touching a command line or exposing private keys.

If you use Commonwealth, discussions will carry over to new testnets when they are deployed. You'll have to re-link your Github identities if you want those to show up.

Otherwise, we will be also posting more (and tweeting at @hicommonwealth). One of our next posts will dive into some of the potential dynamics of Edgeware voting, councillorship, and treasury management.
