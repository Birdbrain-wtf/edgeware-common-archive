We've benchmarked the Wako EVM upgrade using the [raymond.release](https://github.com/hicommonwealth/edgeware-node/tree/raymond.release) branch, focusing on the EVM pallet. The results are:

- 1 unit of gas = 3000-4000 picoseconds of execution time
- In other words, acceptable gas per second = 250,000,000


So far we have conservatively configured gas per second = 8,000,000, making our current block gas limit is 187,500. Benchmarking suggests that we can increase our block gas limit to ~5,800,000 by updating gas_per_second.

We're going to execute an upgrade to Beresheet that raises the allowable gas per second, and then test for stability by running a few scripts to pack the testnet with blocks. In the meantime we can choose to proceed with the Wako upgrade using the currently configured parameters.

To replicate the benchmarks:
cargo build --release --features=runtime-benchmarks

target/release/edgeware benchmark --pallet "pallet_evm" --extrinsic "runner_execute" --repeat 100 --wasm-execution compiled --output /tmp/

cat /tmp/pallet_evm.rs
Results:
/// Weight functions for pallet_evm.
pub struct WeightInfo<T>(PhantomData<T>);
impl<T: frame_system::Config> pallet_evm::WeightInfo for WeightInfo<T> {
        fn runner_execute(x: u32, ) -> Weight {
                (0 as Weight)
                        // Standard Error: 0
                        .saturating_add((4_000 as Weight).saturating_mul(x as Weight))
                        .saturating_add(T::DbWeight::get().reads(2 as Weight))
                        .saturating_add(T::DbWeight::get().writes(1 as Weight))
        }
}
By repeating this process on different computers, including a Macbook Pro M1, Intel Macbook Pro, and 4-core server, using both compiled and interpreted WASM execution, we've seen results between 3000-4000 picoseconds.

Here are the parameters that we're using right now:
BLOCK_GAS_LIMIT = NORMAL_DISPATCH_RATIO * MAXIMUM_BLOCK_WEIGHT / WEIGHT_PER_GAS

NORMAL_DISPATCH_RATIO = 75% (75% of weight available to us)
MAXIMUM_BLOCK_WEIGHT = 2 * WEIGHT_PER_SECOND (2 seconds of each block available for extrinsics)
WEIGHT_PER_SECOND = 1,000,000,000,000 (1 weight = 1 picosecond)
GAS_PER_SECOND = 8,000,000 (configured by us)
WEIGHT_PER_GAS = 125,000
