## **Edgeware solutions**
We propose a treasury explorer solution for Edgeware. 

Main features will include:

1. Lists and metrics about edgeware treasury income. There may be mints, staking remainder, slashes, gas, transfers.
2. Lists and metrics about edgeware treasury output. Mainly about proposals, tips and bounties.
3. Details of outputs while the main feature is the on-chain timeline of the output. For proposals, it may include the proposed extrinsic, motion votes, final result.
4. Metrics about basic treasury status, like real time balance, next burn, spend period info.
5. Metrics of participants, like top beneficiaries, top tip finders, etc.
6. List and detail page about the main funded projects.
7. Price tracker for EDG, and set the fiat cost for outputs.
8. We will not implement account registration, login and comment features for edgeware, since users may not leave their comment from our experience. We can keep it as a treasury business explorer now.

## **General work**

The work will include:

4. Treasury related scan(actually it may involve every block because every block mint edgs).
5. EDG price tracker.
6. Restful api server.
7. Site design for edgeware and implemented with React using the recently updated brand guidelines
