1. What is your experience as a validator or node operator? What other protocols are you validating on right now, if any?

I started of really like a true amateur. My PoS adventure started with the Game of Stakes (Cosmos), where the first round was about the begin and just before launch I thought I would switch to a better machine. Apparently you cannot just recover your keys as a validator and start signing blocks, the validator keys are stored on the machine as well (priv_validator file) and I erased the slower machine. So I started producing no-blocks and didn't understand why. This was a clear learning point and from there on all changed.
Since then on have learned a lot from the basics backing up and not doing something if I don’t fully understand. Soon I’m adding another team member to this project to be more responsive and more expertise. The goal was to learn about proof of stake and since then I think I’m capable of doing this professionally. There is always room for more improvement!
At the moment staking on Terra.money and Kusama and hopefully in the future Edgeware, Polkadot, Cardano and Ethereum.

2. What's your technical setup? (cloud vs. on-premise; software stack; key management)

Using various bare-metals and vps with different cloud providers; always ubuntu 18.04. For the current testnets I use a VPS 8gb,4cpu, for main-net definitely looking for a secure-validator setup on a bare-metal with reserved peers.

3. How did you learn about Edgeware? Why are you interested in validating?

I learned about Edgeware after the first Web3 summit. The idea that Edgeware was aiming for a self-improving smart contract blockchain, was hard to understand and didn’t perceive the implications on the whole ecosystem. After some time, I realized that Edgeware could be one of the cornerstones of the Web3 ecosystem. The big experimental side of it was the attractive element to me as as a node operator and application developer. Also I believe in the Edgeware Network and it's place within the Polkadot Ecosystem!

DAOs, prediction markets, DeFi protocols are the most interesting for me. There is already a lot of work done on all these fields, by good teams mainly on Ethereum hope this work doesn’t get wasted and these contracts can be used in edgeware.

I think Edgeware should aim to fulfill it’s name to the fullest extend. Ethereum had already a huge leap ahead in terms of applications and ideas. It’s nice to know that there is a team working on Polkadot (besides Parity / Web3 ) that has a lot of edge.
