We are going to say that you want to move the Edgeware Validator to a new server and for this to work without having to **rotate** or **insert** the **sessions keys** again, you can copy them from one server to another.

So as of this step you have two servers ready


In the server where the validator is running 
No need stop the validator. 
open:
```cd  ~/.local/share/edgeware/chains/edgeware/keystore ```
```ls```



There are 4 files here, they are the 4 session keys, you must copy them to the new server


In the new server / hosts install the EDG Soft and start the node how sentry, no how validator.
so,
From the new server from where you have the keystore folder empty, the software is installed and the chain is sync the last block, run

```rsync -havz -e "ssh -p 2222" server@IP:/home/user/.local/share/edgeware/chains/edgeware/keystore $HOME/.local/share/edgeware/chains/edgeware/keystore```

here "ssh -p 2222"  **2222** change for your ssh port.

Now the 4 keys will be on your new server.

check here now the folder is not empty anymore
cd  ~/.local/share/edgeware/chains/edgeware/keystore


If oke, stop the other server where is running the validator and start the new one as validator, not as sentry.

> **Note:** *You can double sign and suffer slashed if you turn on both at the same time as validators with the keys. be careful.*
