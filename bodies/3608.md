## **Project overview **

Since the departure of Edgeware’s founding team the project has lacked core maintenance experience, dev ops focus and a collaborative technical culture. As a result the project has fallen behind the main Substrate repo which has created issues with staking, interfaces and is generally not ideal. 

Further to this, upgrades such as ERUP5 have been left in limbo, not just from a technical standpoint but also from a strategic perspective since there has been a talent vacuum. 

Until now various community contributors have added where they can, but the project has needed someone to bind this talent and focus clearly on the chain’s core maintenance and upgrades. Finding talent experienced in Substrate is hard since we are relatively early in the development of the technology and demand is high for those who become available. 

Edgeware's grassroots approach has come about through necessity, but it is also a core project strength, therefore it was key that we recruit someone motivated to contribute to a grassroots community effort - with all the challenges that entails. 

[@Flipchan](/edgeware/account/mdqwzsGFQ8jq2DQ246a9q3FhUAYKrmvNFEfYALXMWiueijV) recently joined the community and after initial discussions with a small group of core EDG contributors we believe he has the technical talent, experience and community values to join the project in the capacity as a core community runtime developer. 

The scope of this work will be for Filip to upgrade the current programming libraries and source code in order to provide more stability and safety. The upgrades will enable new stability patches and added functionality for the node. From here we can look to add/remove/adjust/create pallets and build stronger technical foundations.
