Hi everyone! I want to jumpstart some discussion about how we can build out more interesting zero-knowledge tools for Substrate based chains and especially Edgeware. These can likely be projects we push through and fund with the Treasury as well as other grants from the Web3 Foundation if they strike those folks as appealing.

## Overview
Edgeware and every other substrate chain benefits from being written in Rust and compiled down to WASM.  This allows us to utilise any `no_std` Rust libraries in the native runtime and build interesting applications with tools developed by people even outside the blockchain community.

## ZK Tools on Edgeware
For the past months, from last year on, I've been exploring zero-knowledge tools in Substrate runtimes. My journey started trying to integrate [bellman](https://github.com/matter-labs/bellman) and [sapling-crypto](https://github.com/matter-labs/sapling-crypto) into Substrate, which proved challenging, and eventually settled on integrating the [dalek-cryptography's](https://github.com/dalek-cryptography) tool suite. This tool suite benefits from being written in pure rust.

Some active areas the community here can push forward:
1. Rewrite bellman with `no_std` compatibility as well as the `BN256` curve that is commonly used in Ethereum.
2. Rewrite sapling-crypto with `no_std` compatbility (dependent on bellman) to allow us to deploy roll_ups that are nearly exact to those being built for the Ethereum ecosystem.

## anon (anonymous group constructions and actions)
I've been long interested in zero knowledge applications for voting and mixing coins like [Miximus](https://github.com/barryWhiteHat/miximus) and [Semaphore](https://github.com/appliedzkp/semaphore). My goal within our ecosystem is to bring similar tools to the Substrate ecosystem.

So far, I've been working on a project called [anon](https://github.com/hicommonwealth/anon) which enables group construction and anonymous attestation in the groups. There is one group construction module that uses compact linkable ring signatures to prove membership in the group. I plan to extend this to other constructions, such as merkle tree membership proofs and anything else that proves wise for the community.

I'd love to onboard more people to work in this area and see how we can push this through the Treasury funding route. If people want to discuss *anon* or other zk tools we can bring into this space, discuss below!
