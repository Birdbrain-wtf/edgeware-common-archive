**OVERVIEW**
The [existing](https://beresheet-faucet.vercel.app/) beresheet testnet faucet has been inactive for quite a while now because of which the potential developers are drifting away to other public testnets because of the ease to obtain test tokens. We have developed a new faucet with more functionalities. 

**GOALS**
1. Automatize test token distribution for testing and development on Edgeware.
2. Minimizing entry barriers for new developers by giving them test tokens to play around.
3. This will increase the developer engagement on the network.


**SPECIFICATIONS**
We have added the following new features to the faucet -
- Supports all address encodings as input to send tokens.
- Users can ask for a custom amount with an upper limit to avoid wastage.
- Uses the latest Polkadot API version.
- A banner has been added asking the users to return excess balance after accomplishing their tasks.
- Remaining balance along with the faucet address is being displayed now, so that anyone from the community can refill the faucet to keep it alive.
- Enhanced UI/UX.
