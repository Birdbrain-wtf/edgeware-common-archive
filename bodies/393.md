## Tiers and Qualifications

**"KnownGood" **- Only available for users willing to meet in person, provide their legal name with ID documentation, or via webcam with 2 pieces of corroborating ID. Onchain details must match these IDs. Basically KYC'd.

**"Reasonable" ** - Only accounts with at least one communication channel listed (email, riot, twitter, etc..) will be considered. Each communication channel will be verified independently using challenges. The Reasonable level is only granted to account passing all challenges for each of it's communication channels listed.

Beyond these two affirmative judgements, we also have:

- Unknown - The default value, no judgement made yet.
- FeePaid - The user has paid the fee and verification is in process. I will likely not assign this one until automation is possible, because it must be 'cleared' before granting a new judgement.
- OutOfDate - The Registrar is noting that the data used to be good - perhaps previously Reasonable status, but is no longer relevant.
- LowQuality - Imprecise or not useful, but can be updated to achieve better status.
- Erroneous- Incorrect data, failed challenges, may indicate malicious intent.





## Process

Basically:
1. User sets on-chain Identity
2. User requests Judgement from a specific Registrar and pays any applicable fees.
3. User contacts Registrar for Judgement
4. Interactions with Registrar verify ID
5. Registrar submits judgement.


See more detailed guidance and screenshots at [Edgeware Docs: Identity](https://docs.edgewa.re/understanding-edgeware/identity-module).

**Notes**

- A user may have multiple judgements- so somone who completes both of these criteria sets can be KnownGood and Reasonable.


- If on-chain ID data is changed after a judgement is received, the verification is cleared out and must be re-executed. 


- The only EDG required is the ID bond, and a fee you pay when you request a judgement. You do not need to send any EDG manually to a registrar ever. They will get the fee from the system when they complete the judgement.
