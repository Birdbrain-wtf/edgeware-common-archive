We’re right around the corner from the Edgeware network launch--00:00 UTC on Sept 15, 2019, at (8 pm EDT on Sept 14, 2019). At that time, validators are expected to start their nodes and start producing blocks. A few parameters have been chosen so that this can smoothly proceed. You can inspect the [recommended launch spec and node here](https://github.com/hicommonwealth/edgeware-node/). 

In some ways, the Sept 15th network start can be thought of as a soft launch or betanet. At Commonwealth Labs, we encourage the community to lift the parameters once they feel the network is stable. The community may feel that “fully launched” Edgeware will only take a month’s time, the community may decide it will take longer. At the end of the day, Edgeware governance is a community-led process. We detail the parameters below:

- `TransferFee: Balance = 999999999 * DOLLARS`

Fees for token transfers set to 999,999,999 EDG. Recall that the network has 5 billion tokens at genesis. By setting the fee at this amount, addresses will be limited in their ability to perform transfers. Again, in order to enable transfers, the governance process of the network must perform this update.

- Slashing at 0%

The current validators on the testnet are helping to stabilize edgeware-node, in real-time. In the early days of the new network, there may still be unintended events that occur. To mitigate this, the slash percentage will initially be set at 0%, from the standard 10%. 

- `validatorCount: 60`

The current validators on the testnet has produced over 100 thousand blocks--[viewable here](https://telemetry.polkadot.io/#list/Edgeware%20Testnet). We want to make sure that the 6-second blocktime is able to be reached. To ensure that the validator set would be filled for the soft launch, validator fulfilled a [few community guidelines](https://commonwealth.im/#!/edgeware-testnet/proposal/discussion/20) to be included in the recommended genesis spec. After that first block is created, anyone may bond for a validator slot. There is no difference between a validator who is present for the genesis block and those that bond afterward.

- Target bonding and nomination rate: 80% of network

Edgeware’s staking module allows the network to target a level of participation and vary inflation to incentivize behavior. If 80% of the network is staked, the overall reward to validators should be 10% of the genesis allocation. This is what we specified in the original whitepaper.

- `desired_seats: 6`

The council module supports a set of users to be voted in to better influence network governance. Initially, Edgeware is set at genesis with 6 council seats, While one seat will initially be allocated to Commonwealth Labs, the 5 remaining seats are open to community campaigning! The number of seats should grow as the set of stakeholders matures over time. See the [whitepaper](https://arena-attachments.s3.amazonaws.com/4643268/c8d128724f36b716660e4bf21823e760.pdf?1563310093) for more details and explore [council on Commonwealth](https://commonwealth.im/#!/edgeware-testnet/council).

- `sudo`

Before the network stabilizes, the betanet includes a root key that allows for fast enactment of emergency proposals. Even during this soft launch period, Edgeware governance proposals take 4 weeks to create an on-chain change--a 2 week voting and 2 week cooldown period before implementation. In certain scenarios, 4 weeks may be too long to wait. However, within the first week of the network soft launch, a democracy proposal will be created to permanently disable the root_key. Currently, the root key is assigned to a Commonwealth Labs public key. We trust the community will vote to remove this power! 

TLDR. In order for the network to succeed, the community will need to change several of the above parameters, in particular:

- Disabling the `sudo` module
- Reducing the `TransferFee`
- Increasing slashing

By calling the Edgeware network a soft launch or ‘betanet’, we want to highlight the uncertain, but dynamic circumstances that will take place over the course of the first month! Let the games begin (on September 15th UTC)
