## Background information
A few month ago Parity release the `v14` of the Substrate metadata. It introduce the crate `scale-info` and the trait `TypeInfo` that can be implemented on any type making it self descriptive for other programs, making the `#[pallet::metadata` macro obsolete. When using it you don't have to manually declare your custom types in order to interact with the chain API. For those familiar with ethereum-smart contract, it can be seen way for the runtime to self describe its ABI.

## Problem statement
This feature being a really nice improvement to the metadata mechanism, it seems useful to adopt it for Edgeware, which is currently using the v12. The process of migrating to metadata v14 is not complex, but it require to be done consistently in all the pallets of the chain. A basic comprehension of Substrate is required to execute it properly.
This has been requested by @thomivy on github:[ https://github.com/edgeware-network/edgeware-node/issues/4]( https://github.com/edgeware-network/edgeware-node/issues/4)

## Proposed solution
 My team and I will do this migration to metadata v14 for the Edgeware runtime.
