## _Meta _
_Proposed by Validator Luckyve_


**This proposal if passed, would boost the validator set limit from 85 to 100. **



## Discussion
Considerations as I see them:

- The 85-limit currently holds about 21 on the Waiting list (aka 'Intentions') - leaving 6 intentions if we boost it to 100. 


- Recently, conversations in chat note that some validation operations may be refraining from running their total intended nodes (so we can add a few to our current Waiting list pending technical resolution or other reasons these vals may not be running all their nodes yet.)


- When we boost the validator set limit, the reward is further diluted among active validators - because currently,  the absolute inflation hasn't been altered.  We saw this occur to the surprise of some validators and nominators after the last boost.
