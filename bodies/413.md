Thought it would be useful to collect our thoughts and notes on blocktime - not merely the 6s blocktime but how we define sessions, eras, etc. 

## CURRENT 
**Block** 6 seconds
**Epoch **60 minutes
**Session**  600 Blocks 
**Era** 6 sessions

```
CURRENT
pub const SessionsPerEra: sp_staking::SessionIndex = 6;        
pub const BondingDuration: pallet_staking::EraIndex = 28;        	
pub const SlashDeferDuration: pallet_staking::EraIndex = 28;	
```

## AFTER  1ST TECH UPGRADE
**Block** 6 seconds
**Sessions** 1 Hour (600 blocks)
** Eras** 6 hours (6 Sessions, or 3600 blocks)
**Bonding duration** will also change to 28 eras (7 days / 168 Hours)



## Additional Runtime Code and Parameters
```
pub const MILLISECS_PER_BLOCK: Moment = 6000;
pub const SECS_PER_BLOCK: Moment = MILLISECS_PER_BLOCK / 1000;
pub const SLOT_DURATION: Moment = MILLISECS_PER_BLOCK;

// 1 in 4 blocks (on average, not counting collisions) will be primary BABE blocks.
pub const PRIMARY_PROBABILITY: (u64, u64) = (1, 4);

pub const EPOCH_DURATION_IN_BLOCKS: BlockNumber = 1 * HOURS;
pub const EPOCH_DURATION_IN_SLOTS: u64 = {
const SLOT_FILL_RATE: f64 = MILLISECS_PER_BLOCK as f64 / SLOT_DURATION as f64;

(EPOCH_DURATION_IN_BLOCKS as f64 * SLOT_FILL_RATE) as u64
};

// These time units are defined in number of blocks.
pub const MINUTES: BlockNumber = 60 / (SECS_PER_BLOCK as BlockNumber);
pub const HOURS: BlockNumber = MINUTES * 60;
pub const DAYS: BlockNumber = HOURS * 24;
```
