We've had an existing team go through the grant process, in this case for the [staking UI](https://commonwealth.im/edgeware/proposal/discussion/454-staking-ui-grant-proposal-draft). It's a great start, but there's much more the treasury can do. The purpose of the treasury is to achieve self-sustainability and permit creative incentivization of all stakeholders in the ecosystem—not merely validators through the block reward. We imagined that the treasury would support core and app development, various forms of ecosystem support, and much more as the community's creativity and judgment allows.

**Current List of Proposed Grants (Propose Your Own!)**

This is an ever evolving process, but it's important to get things started somewhere. To that end, we've put together a list of **[proposed grants here](https://www.notion.so/hicommonwealth/Grants-fd8027cd457940c8b04f5d3862a4d4de)**. We'd like to invite the community to contribute to the list directly in Notion (or comment directly in the thread below). These grants are centered around a few core areas:

1. **Core Dev**: new runtime features like bridges, contract functionality, and or privacy additons
2. **Incubate**: new project that may have their own token. Such as using the Edgeware Treasury to allow better rates on an Edgeware Stablecoin.
3. **Dev Tools**: Making it easier to developers to build dapps, interface with the node and more.
4. **Governance**: Additions to the treasury module or changes to the council and other structures to decentralize power.
5. **Network Effects:** Growing the set of users that Edgeware can reach. Potentially attracting devs with interesting "social / governance" features, for example an incentivized Humanity DAO.
6. **DOT Bond:** Getting access to DOTs to bond as a parachain


We'll probably build out some features on Commonwealth to make this process more smooth, given that existing grants are already processed here. As conversation occurs in Riot, Telegram, and other community channels, we'll try to keep this document as updated as possible!

**Applying for a Grant**

Through the existing Governance Working Group calls, the community workshopped a questionnaire to serve as a proposal descriptor and application. Commonwealth Labs has expanded on the functionality of this document, [which can be found at the Treasury page at the Edgeware Docs](https://docs.edgewa.re/understanding-edgeware/treasury), into a technical process that maintains accessibility and transparency as applicants seek resourcing. **[Here's a link to the proposed grant template](https://www.notion.so/hicommonwealth/Grant-Your-Title-e59cec0231fd4c60b5fff16a01f19e94)** for projects to work through the grant process.

As individuals propose grants, it's probably easiest to make a copy of the Notion Document, and create a thread on Commonwealth to continue more in-depth discussion.

- To succeed, projects should consider confirming to [the project concepts guidelines.](https://docs.edgewa.re/understanding-edgeware/treasury#plausible-project-concepts)
- To ensure ease-of-use we require all projects to create documentation that explains how their project works. At a minimum, written documentation is required for funding.
- Payment will be performed at the completion of milestones (or at end of project if specified in grant application) upon approval by the council. In exceptional cases, up-front deposits may be made to reputable teams.
- Understand [how Treasury Proposals are Approved](https://www.notion.so/hicommonwealth/Grant-Process-8604e997781444a1a21f2d2c1a6a4e83#07b849801f914af59b5e1fa9e7502826), and that Edgeware proposals are reviewed openly by decision-makers and the community.


**Future Grant and Working Group Process**
While this is likely too much process to add right now, in the future, it would be interesting to have the Working Groups be aligned with the set of proposed grant areas. Working groups would work on an end to end process of proposing ideas, discussing the ranking and sizing of projects, sourcing of teams, and making recommendations to the council on if a treasury proposal should be passed. I'm excited to see how things shape up in the future.
