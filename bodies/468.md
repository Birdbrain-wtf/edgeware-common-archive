Vitalik had a semi-recent tweet about a "third way" chain that would take the political tradeoffs that ETH/BTC don't take. It seems like Edgeware is 1/3rd of the way there, with on-chain governance.




This was followed up by a thread on ethresear.ch on an [Enshrined Price Oracle](https://ethresear.ch/t/enshrined-eth2-price-feeds/7391), where validators would also offer this. It seemed like the consensus in that thread was not to move forward, but seems like an example of a feature that Edgeware as a community could implement and fund through the treasury.

As specified in the above thread, there is no economic slashing. If an enshrined price feed were implemented on Edgeware, the network could add economic slashing as well as additional rewards, where a subset of validators opt in to earn additional rewards by reporting this feed. This would probably have to be implemented as an additional runtime module.

I guess there are a few follow up thoughts / actions:
- [ ] Talking through chain positioning, and the feature set to continue building towards (I.e to extend governance)
- [ ] Understanding how this chain positioning impacts the sets of developers that we would be able to attract
- [ ] Specifically talk about the Enshrined Price Oracle. From a dev perspective, oracles are a perennial attack vector, especially for DeFi. Offering a solution baked into the chain seems very helpful. My main concerns would be if there is a dev team that could champion a discussion around the economics / development of such a proposal
