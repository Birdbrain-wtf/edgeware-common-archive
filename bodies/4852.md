## Summary
This is a request for funding for **completed work** delivering "pallet_mint" that enables the direct minting of new network currency (KAB/EDG) to a project team or multisig after a public referendum has been approved.

This functionality is aimed at reducing the complexity of Substrate chains which have so far instituted chain treasuries, where inflation, fees and slashes of validators is redirected into a 'treasury address'.

By minting new currency upon a funding approval, network inflation is directly correlated to the creativity of project teams and the continued benevolence of holders. 

The additional effect is to remove some of the psychological challenges that tend to occur with network treasuries that hold a native currency that fluctuates wildly. When the price is up, spending tends to be more profligate, whilst when the price decreases conservatism creeps in. "Pallet_mint" seeks to overcome short term thinking and prioritise longer term thinking. 
 
## Technical overview
The pallet adds functionality to mint a value on an account, and to optionally mint a percentage of this value on another account (as a fee). It also provides an extrinsic to change the percentage value.

The calls have to be from Root, so as a Democracy proposal, or as a sudo call.

## How it works
Get the proposal amount, and compute (if needed) the value of the fees

Then use `deposit_into_existing(accountId, amount)`: This will mint the `amount` on the `accountId`. 

We can also use `resove_into_existing(accountId, imbalance)` to manage the imbalance.

## Funding Terms
We are introducing new implementation based terms to [Edgeware and Kabocha's recoup model](https://gov.edgewa.re/discussion/3806-kabocha-funding-and-edgeware-recoup).

If Edgeware utilises Pallet_mint within its runtime then it will share costs 50/50 with Kabocha. 

If Kabocha is able to recoup Edgeware before Pallet_mint is installed in Edgeware then Edgeware will be entitled to a full recoup.

If Edgeware later installs Pallet_mint then Edgeware will return 50% to Kabocha. 

This is to be agreed and managed in good faith by both projects.
