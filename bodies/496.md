## About Blockx Labs

We are a team of blockchain developers with expertise in building developer tools and an enjoyment of open source projects. You can check out our work at our [Github ](https://github.com/blockxlabs/).  We are also the developers behind the testnet Edgeware faucet, and are familiar with the network through our work on wallets and dapp explorers.

We have built Enzyme - a browser extension wallet for Substrate-based chains, currently supporting Kusama and Polkadot. It can be downloaded for [Chrome ](https://chrome.google.com/webstore/detail/enzyme/amligljifngdnodkebecdijmhnhojohh?hl=en)and[ Firefox](https://addons.mozilla.org/en-US/firefox/addon/enzyme). 

The wallet allows the user to: 
1. Check balances 
2. Send & receive tokens 
3. Allow DApps to sign messages 
4. Use an address book built to improve the user experience.


We have had several discussions with the Commonwealth team over the year about both our faucet and extending the wallet functionality to support the Edgeware network. With the wallet development wrapping up, we’re looking to finalize the integration of EDG to provide options for users in the Substrate ecosystem, but also to forward our view of a more modular approach to wallet development.

**A browser extension wallet is essential in creating a DApp community for any network.** Without a browser extension wallet, DApps can’t access the private key functionalities including signing, and this interferes with a smooth user experience.  Having an extension-based wallet similar to Metamask will enhance both the holder and developer experience. 
We have written a couple of medium articles regarding this. You can find them at 
- [Why and How to Build Metamas for your Own Blockchain ](https://medium.com/hackernoon/why-and-how-to-build-metamask-for-your-own-blockchain-7d6fb305e5a6)
- [Enzyme’s First Milestone](https://medium.com/hackernoon/celebrating-enzymes-first-milestone-f37afb8b8a45)
