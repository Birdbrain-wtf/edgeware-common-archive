As we approach the mainnet Edgeware upgrade to Substrate 2.0 rc3, we want to give an update of the recent work that's gone on. Most of which has culminated in a new testnet, called Beresheet (meaning "in the/a beginning").

This testnet runs off the version 3.0.8 Edgeware node, recently pushed to release in a testnet mode. We have yet to push this release to the master branch and will do so soon. We plan to run this testnet for as long as the community finds desirable before moving forward with the upgrade.

This testnet was launched at the beginning of the week of August 2nd with the same genesis spec as Edgeware. The only changes are to the initial validator set which Commonwealth Labs maintains at the moment. Once the chain was launched, it was left running for a few days before running our pending runtime upgrade. This was run early to ensure we have a few weeks or longer to test out the upgraded chain, its functionality, and more. There was feedback from the community that was well received and will inform how we can do a better job around these upgrades in the future.
Namely,
- Larger announcement of testnet prior to running a runtime upgrade.
- Incentivization of node infrastructure for the testnet.
- There are some early ideas here, but this probably looks like getting tipped from the Edgeware Treasury with various milestones for continued tips/payments.


With that said, we want to open up an validators-only announcements channel to keep people upgraded on node updates and new testnets. If validators are able to add their on-chain identity and Telegram or Riot name, we can add individuals.

Nonetheless, we are interested to get more participation on the testnet, deploy contracts, and get feedback about how it is working currently. We are working to smooth out any rough edges at the moment too!
