I've compiled a working upgrade against the mainnet runtime, which takes Edgeware mainnet to Substrate 2.0 rc3. This runtime can be tested and upgraded from the v1.0.1redo  branch and anyone interested in running an upgrade can deploy the binary linked below to test it out.  As has been communicated in Element, it is expected that all nodes running this upgrade be running the v3.0.8  Naples software release or later versions in order to be compatible after the upgrade.

## Node support
As has been communicated, the upgrade will cause breaking changes in old nodes at versions less than 3.0.8. Therefore, you are strongly encouraged to update your node software to the Naples release in order to not have to upgrade after an upgrade and risk being slashed on chain. The node release is linked below:

[https://github.com/hicommonwealth/edgeware-node/releases/tag/v3.0.8](https://github.com/hicommonwealth/edgeware-node/releases/tag/v3.0.8)

## Testing and replication
In order to test it, we strongly encourage people to run the upgrade in local development networks to assert the compatibility of the upgrade as well as the trustworthiness of it.

The upgrade binary in a Gist: [https://gist.github.com/drewstone/23c404c57375dc886ead04078a8e5548](https://gist.github.com/drewstone/23c404c57375dc886ead04078a8e5548)
