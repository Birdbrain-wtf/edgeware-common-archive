Users have reported that addresses pre-upgrade with a **non-zero** balance are now showing a **zero** balance. To correct this, an extrinsic system.MigrateAccounts needs to be called to manually migrate your balance. A Commonwealth team member can help with this transaction, to request help please add your account and contact info to **[this form](https://forms.gle/itrjGK62hbACjLAH6).**

Here's an example below, using the Polkadot UI with the target address(es).

![](https://commonwealth-uploads.s3.us-east-2.amazonaws.com/3f7c9035-54fb-4028-a1e2-29f12ea062bb.1600971772484)

Please note, this only affects accounts that have been created within the previous 30 days. If your account has been created prior to the last 30 days, your balance should have automatically been migrated.

We're sorry for any inconvenience this may have caused!
