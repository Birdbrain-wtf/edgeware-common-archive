## **Summary **
This was an [initial call ](https://commonwealth.im/edgeware/proposal/discussion/631-community-call-with-mocda-artist-residencies-301020)to discuss the Edgeware Artistic Residencies programme which has been spun off from an initial Brand Working Group discussion into a new group. 

The aim is to develop and launch an ongoing grants programme that will introduce an open-call for artists and creators from around the world who can submit proposals for and receive funding, support and development expertise from an emerging network of talent. 

The aim is for this to become the foundations for a self-sustaining arts/culture-economy on Edgeware. 

Potentially assets created can be pooled into Edgeware treasury or address and build ‘artistic collateral for the public good’. 

- Solve the problem for artists as conveyed by Jon: art economic model broken.
- Support interoperability as a foundational value.
- Generate a space for artists, built by artists, for artists, in perpetuity using regenerative financing.
- Long term goal - build a global & borderless ‘Arts Council’ - see [here](https://www.artscouncil.org.uk/letscreate). 


> **Mission: Solve the equity / ownership / values around value capture for artists**
> **Vision:  Where Artists Create the Space For Artists**
