## **Browser Extension**

![](https://commonwealth-uploads.s3.us-east-2.amazonaws.com/2363ab02-2a37-4f77-afc5-6ffd7a8d8cd0.1661875341532)

Edgeverse Browser Wallet supports Edgeware Mainnet, Edgeware EVM, Kabocha Mainnet, Beresheet Testnet and Soupcan Testnet. It supports Dapp access just like Polkadot,js and Metamask.Firefox Browser approved the extension/add-on and it's available in add-ons store. Review pending in Apple Safari Browser. Unfortunately it's rejected by Google Chrome and Microsoft Edge Browsers as it only supports Manifest V3 from now on. We will update it to Manifest V3 as soon as possible.
**Features**
- Edgeware Mainnet, Kabocha Mainnet, Soupcan Testnet, Edgeware EVM Supported.
- Metamask Inspired Interface for Edgeware EVM.
- Import Custom Tokens support for Edgeware EVM.

**New Plans for Extension**
- Staking Option for Edgeware and Kabocha
- Transfer Option Between Edgeware EVM and WASM
- NFT Support.

**Problems**
- ERUP5 Upgrade - EVM Transfers not working.
- Removed the Beresheet option for now, We will add it once it's back to normal.

**Firefox Add-on Link**
[https://addons.mozilla.org/en-US/android/addon/edgeverse/](https://addons.mozilla.org/en-US/android/addon/edgeverse/)
