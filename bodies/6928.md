## **Detail**

**Edgware’s simple UI** is live simple.edgeware.app. The goal of the project is to give a better overall experience for new people to have an easier time starting in the Edgware ecosystem and eventually to move on to a more advanced UI like edgeware.app. I removed many advanced features, kept the essentials, and made it more visually appealing. I had difficulty deciding if and how to make the functionality easier for users. When you make decisions for users, the user loses a lot of control, and I didn’t think it would be a good idea to do that; however, if anyone has feedback on how to improve the user experience technically, that keeps the decisions to the user. I am open as the new simple UI is a good testing environment to try and test these things.
