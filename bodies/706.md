**Summary**
Edgeware gets new working groups, the New York Upgrade gets closer to execution on-chain, and the council learns about governance experiments while the Brand Working Group plots their film project.

### Development
- Reminder: The New York Upgrade is in governance queues, and includes:
- [Assets pallet integration](https://substrate.dev/rustdocs/v2.0.0/pallet_assets/index.html)
- [Bounties pallet extension for the Treasury](https://github.com/paritytech/substrate/pull/5715)
- [WASM contracts pallet upgraded to Ink! 3.0](https://github.com/paritytech/ink)
- New GRANDPA extrinsics for noting finality stalling
- Pallet weights consistent with Substrate's default weights
- Identity migration to recover identities at improperly hashed keys
- New York **Parameter changes:**
- Max locks per account set to 50
- Max council members set to 100
- Bounty deposit base set to 10 EDG
- Bounty deposit payout delay set to 7 days
- Bounty curator deposit set to 50% of bounty
- Bounty minimum value set to 100 EDG

### Governance
- Drew and JAM attempted to speed up the runtime upgrade proposal, although unsuccessfully. It was a learning experience nonetheless and we will investigate why the workaround did not work.
- To summarize, Drew attempted both to cancel the existing referendum to upgrade the chain as well as propose a new one, using the democracy's external proposal mechanism, to enable the new proposal to be fast-tracked by the council. If it had worked correctly, it would have saved an execution cycle for processing governance proposals.
- Nonetheless, the active runtime upgrade will remain up and be voted upon as usual.


### Community
- Working Groups have become a major driver of network development and partnerships, but what are they exactly and how can you start one? [Read up on the Primer](https://commonwealth.im/edgeware/proposal/discussion/702-edg-working-groups-a-primer) from Thom Ivy, and if you have a mission or community you think would benefit from Edgeware support, reach out!
- Mr. Bulb [offers a plan for community development](https://commonwealth.im/edgeware/proposal/discussion/705-edg-governance-treasury-community-waterfall) he calls a 'waterfall' that tracks the historical process of development and provides a map for users and projects looking to get involved.
- [The Edgeware Meme Contest is running!](https://commonwealth.im/edgeware/proposal/discussion/637-repeating-meme-contest-memedg-tournament) Share some EDG memes and the Council will judge the best. The first winner just won 1000 EDG and a chance to win more in the October Bonus round.
- Edgeware Runtime developer Drew Stone [opens a discussion on an idea called a zkBridge](https://commonwealth.im/edgeware/proposal/discussion/694-zkbridges)- where bridges between chains become mixers providing privacy on the interactions.
- Thom Ivy [asks what chat platform should Edgeware default to](https://commonwealth.im/edgeware/proposal/discussion/692-using-discord-for-working-groups-or-other-community-platform-changes), although bridges make using several fairly easy. With Working groups growing, it's becoming more difficult to keep everyone within arms-reach.
