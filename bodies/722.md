Right now, it's difficult to tell what the threshold for successful actions pertaining to council motions, democracy actions, etc. are -- you can submit actions, have them technically succeed according to their own parameters, but fail to execute as they fail the check on the chain's threshold requirements. 

Jam says that for an action: "You need to go to the runtime and check out what you want to do, so if it's a treasury proposal, there should be an approveOrigin in the runtime that you can ctrl+f" and that "every pallet declares its own origins, so unfortunately it's not uniform at all."

An interface tool that reads and displays these or as part of our communication of runtime parameters is a small project that might be worth a bounty.


To view the thresholds in the runtime:
[https://github.com/hicommonwealth/edgeware-node/blob/master/node/runtime/src/lib.rs](https://github.com/hicommonwealth/edgeware-node/blob/master/node/runtime/src/lib.rs)

	>;
