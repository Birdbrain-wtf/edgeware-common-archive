**Tech**
Reminder: The New York Upgrade is roughly 5 days from execution, and includes:
- [Assets pallet integration](https://substrate.dev/rustdocs/v2.0.0/pallet_assets/index.html)
- [Bounties pallet extension for the Treasury](https://github.com/paritytech/substrate/pull/5715)
- [WASM contracts pallet upgraded to Ink! 3.0](https://github.com/paritytech/ink)
- New GRANDPA extrinsics for noting finality stalling
- Pallet weights consistent with Substrate's default weights
- Identity migration to recover identities at improperly hashed keys

New York **Parameter changes:**
- Max locks per account set to 50
- Max council members set to 100
- Bounty deposit base set to 10 EDG
- Bounty deposit payout delay set to 7 days
- Bounty curator deposit set to 50% of bounty
- Bounty minimum value set to 100 EDG


We've also integrated ChainBridge's trusted bridge modules into the develop branch and have configured the system locally for an ETH <> EDG bridge.
- With a bit more testing we hope to launch on the Beresheet Testnet soon.
- We are speccing a UI to utilise the bridge and will collaborate with chainbridge-ui or extend it to our own benefit.
