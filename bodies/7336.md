## Context of the proposal
OpenSquare developed dotreasury implementation for edgeware with the support of #40 proposal. It outlines the income/outcome status of the treasury account, shows the list and detail of proposals, bounties and tips. Generally it makes the treasury status and workflow more clear.

## Request details
The maintenance fee covers:
- Server hosting and maintenance labor
- Bug fixes
- Small interfaces tweaks
- Proposal information manual maintenance

The detailed work includes:
- Home page total income/output precision fixup 
- Bounty overview fix up 
- Add curator column for proposals 
- Improve polkadot identity avatar 
- Daily monitor the scan process 
- Add context and links for proposals

The time scope is 02.2022 ~ 12.2022.
