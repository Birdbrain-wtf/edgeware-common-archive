### Governance
- In order to restore finality to the chain, the New York runtime upgrade exposed a feature to governance. [**Council Motion 20](https://polkadot.js.org/apps/#/council/motions)** aims to resolve the finality issue through the following: "The current authority set of the GRANDPA finality gadget has stalled. This will trigger a forced authority set change at the beginning of the next session, to be enacted [some] delayed blocks after that. The delay should be high enough to safely assume that [the block that signals] the forced change will not be re-orged (e.g. 1000 blocks). The GRANDPA voters will start the new authority set using the given finalized block as base. Only callable by root."
