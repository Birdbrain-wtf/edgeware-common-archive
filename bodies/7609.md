This is an appreciation post for the voluntary contribution by [Eliott Teiss](https://twitter.com/EliottTeiss). They have contributed in the form of daily docker builds of the Edgeware node. 
They have employed a code script which collects information related to any updates from Github and creates a new docker image of the same. Further, this docker image can be used by validators, RPC infrastructure providers, exchanges, wallets, explorers and EdgeEVM/EdgeWASM protocols to set up their nodes. These daily builds have been there for over 2 years now.
Recently, they switched their source repository from the [Commonwealth Edgeware Node to the Edgeware Network Edgeware Node](https://github.com/ETeissonniere/substrate-nodeops/commit/6c37d0c07cb9882085472fe3c76629cc4b746727) repository, which means they were building images for Edgeware v3.3.6, but now after the change in the source repository, they are compiling images for Edgeware v4.0.2. In addition to this, we are expected to have docker builds for all the new Edgeware version releases hereafter.
Based on the above information, we can understand that this is a very useful technical domain contribution and will be helpful to the Edgeverse community members wanting to set-up their nodes. Thus, proposing a treasury tip as an appreciation for this contribution.
