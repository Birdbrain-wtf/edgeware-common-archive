OnFinality is a SaaS platform that provides infrastructure services for the Polkadot/Substrate community. [We just launched our beta version of a shared node API Service](https://onfinality.medium.com/onfinality-is-pleased-to-announce-its-api-service-beta-ce57ba8c7554), which expands on [our core mission](https://onfinality.medium.com/our-mission-fb3bb862841e) - to support all blockchain developers in the world by providing core infrastructure so they can focus on building the next dApp.

Setting up blockchain infrastructure is difficult and time consuming, and requires a level of server development expertise that many don’t have. OnFinality will implement and run a network of shared Edgeware public nodes on our API service for your users to access.
- This funding grant consists of two key components:
- This treasury application relates to the Initial one off setup costs to deploy and enable a pool of Edgeware nodes on the OnFinality web application
- A future treasury application will apply for ongoing running costs of this pool of Edgeware nodes, currently estimated at $1065.20 a month
- We plan to run a pool of public Edgeware nodes initially.
- We’ll maintain our free tier for Edgeware users of 500,000 requests a day while funds to run these nodes remains
- We’ll provide additional paid tiers of API Service usage above those 500,000 daily requests at different costs structures
- We’ll maintain the one click deploy dedicated node access to Edgeware for customers that go above what our API service is intended f**or**
