The last couple months have seen an explosion in activity in the Edgeware ecosystem. We've onboarded new chain hires, new developers, and started on a number of awesome new projects to make 2020 a truly successful year for Edgeware.

At the top, we've executed 3 upgrades this year. The most recent upgrade brought us up to par with Substrate 2.0, cleaned up missing identity migrations, and allowed us to fix finality stalling on the network. As we wrap up this year, we intend to push forward another upgrade, one that brings ChainBridge bridge support to Ethereum and hopefully includes EVM support, which we are working to test and bring up to speed with the rest of our runtime. With all this said, this leaves us bonding to become a parachain to fulfilling the Edgeware 2020 technical roadmap.

In addition, we along with other community members have begun working on several projects that should help guide the roadmap for 2021 and improve the developer experience:
- _**2 Ink! smart contracts:**_ A HumanityDAO style contract and an atomic swaps contract
- _**Edgeware mobile application template**:_ A rust/flutter app for transfering EDG.
- _**Zero-knowledge pallets**_: A ring signature pallet and a merkle tree membership pallet.
- _**Identity offchain worker pallets:**_ A URL verification pallet for Github + Twitter and a Twitter scraper pallet for querying Twitter account mentions.
- _**ChainBridge integration:**_ Integrating the pallet for trusted ETH/EDG bridge.
- _**ETH Light client offchain worker:**_ An offchain worker pallet to relay Ethereum headers and create verification proofs.


Overall we've started on a number of new initiatives with new developers:
- We've spun up [contracts.edgewa.re](https://contracts.edgewa.re/#/) for Ink! developers (our WASM based smart contract engine)
- We've spun up the [Edgeware Builders](https://github.com/edgeware-builders) Github organisation, featuring active projects in development and already deployed.
- We've created the [Construction Projects](https://github.com/edgeware-builders/construction-projects) repo for tracking project ideas from ideation to execution and posting grant ideas.


As always, if anyone knows developers interested in working on new cutting-edge projects, smart contracts, and interfaces for them, please don't hesitate to send them my way! The Builders WG is always looking for new contributors, and I'd be happy to guide them along.
