What's an Edgeware Wallet?

It's a crypto wallet for Edgeware implemented in Rust and Flutter. It doesn't rely on Polkadot.js and instead, it uses Rust directly to achieve speed and security. It uses hardware-encrypted storage to store the secret keys.
