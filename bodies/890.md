A quick update on my forays in the UMA-verse. I've finished the DeFi-Academy course. It outlines a minimal implementation of a derivatives platform using Remix and Solidity. The contracts are not production-ready, but it teaches the basic UMA architecture.

I don't think it's useful at this point to fork UMA on Edgeware or rewrite the code in Rust. In my opinion it is smart to dock on to this existing and well-advanced protocol with its clever priceless design. In case of a price request a smart contract call can be bridged to the UMA Data Verification Mechanism on Ethereum. There is no need for a fast execution of this call, the bridge wouldn't form any hindrance thus. Price requests ask UMA token holders to vote on the value of a price identifier at a historic timestamp. This process takes 2-4 days where said holders commit and reveal their votes on-chain. 

All synthetics are backed by collateral, ideally by DOT, KSM and EDG. Seeing that D-trade will first use a couple of ERC20 tokens as collateral, the preferred ones are not possible to use yet. I don't have an overview of which of the UMA contracts need to be redeployed on Edgeware.

This morning I had a meeting with Edson Alcala from UMA, who created the course. He is working on an UMA Plugin for Remix. My feedback was that he should focus on making it as easy as possible to launch production ready synthetics that integrate with UMA. He too had thought about deploying on another chain and that we could do this together!
