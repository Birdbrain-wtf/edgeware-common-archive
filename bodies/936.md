# Tokyo Upgrade Pre-release
As has been stated on Element, the Tokyo upgrade is shaping up nicely! As always, the feedback at this point from our validators and node operators is extremely helpful, since this upgrade is not backwards compatible. We are working to understand issues with the node running after update on the Beresheet testnet and would appreciate any help on the matter. Tips and grants to help in this regard for offsetting costs will certainly be supported by myself, Drew, on the matter.

## Changelog
We have integrated the following updates to the Edgeware runtime:
- New **Assets** pallet functionality with new trait allowing future runtime modules to interact with assets.
- **EVM / Ethereum** compatibility using **Frontier**
- **Faster governance times**
- 2 day launch period for democracy proposals (the _seconding_ stage)
- 4 day voting period for democracy proposals (the _voting_ stage)
- 1 day enactment period for democracy proposals (the _enactment_ stage)
- **ChainBridge **modules for bridging EDG to Ethereum.
- Added two testers and better CI to the repo
- Upgrade tester to ensure state exists before/after upgrade
- Frontier tester to ensure larger smart contracts can be deployed such as Uniswap.
- Removed **Signaling** and **Voting** modules due to lack of usage and to clean up runtime as much as possible.


## Potential additional updates
- Updating **SpendPeriod **to anything less than 2 weeks, which it is currently set to.
- Updating any of the governance parameters to suit a majority of opinions.
