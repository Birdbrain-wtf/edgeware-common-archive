**Bootstrap Phase**

Outside of this, [@drewstone](/edgeware/account/hwR8hAatmmdupBLXQSxLUPBa8GhRomLD9hf6iRtFeXs8fcY) has also asked how we can be more aggressive using BuilDAO. I think at this point, as a community, we can start to "pre-commit" to these projects while going through the open application, open discussion process.

What I think this will look like in the next month or so is the following. As the EVM pallet comes online, a MolochDAO will be created that has shares. This will be able to be seeded with a "token" amount of EDG, individuals will be able to participate in this, as scouts, experts, and more. Note, we can use a Commonwealth Forum for the MolochDAO. Commonwealth Labs has a MolochDAO integration set for this!

Scouts, experts, and projects can apply here and we can use this as a process on onboard community members that will actively participate in BuilDAO. Then, as the legal work concludes, we should be able hit the ground running, allocating DAO Shares to those whom participated in the bootstrap phase as well as projects that BuilDAO bootstrap members participated in.

This bootstrap phase can also be used to adjust any of the DAO rules listed in the [original proposal paper](https://www.notion.so/hicommonwealth/BuilDAO-Incubator-Paper-35d451f814014f9cbff96b6c8ab443a4) specifically around members and project onboarding!
