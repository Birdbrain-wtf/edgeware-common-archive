Building good, useful development tools is necessary for blockchain success, but it also requires funding - and it can be hard to ensure developers get the resources they need without a clear plan for supporting long-term innovation and development in a network.

**What are some funding options that have been explored for dev tools?**

Grants are one of the most common ways to get funding for building. Web3 and the Ethereum Community Fund are some of the biggest entities in this space offering grants to those who apply. Aragon, which at the time of writing was listed at number five on the State of the dApps ranking for chains with the most development activity in September 2019, also introduced the Aragorn Nest program in 2017 to facilitate grants for those looking to further development of the network. The Nest program works with a venture capital firm called Placeholder.

**How could sustainable development for a chain be driven by the community?**

One option for using a native currency to fund development that the Stellar network has implemented is an inflation pool that funds projects by user choice.

The Stellar protocol has an inflation mechanism that adds 1% inflation of Lumens (XLM) to the pool each year. Users can vote to use money from the inflation pool to support different projects that they believe are significant for the Stellar network. If a user votes for a project, the project will receive 1% of that wallet, to be distributed every week.

It isn’t quite so simple as being able to donate inflation money to a project you think is worthy, though. A project won’t actually receive inflation pool money unless it reaches a certain amount of tokens designated for it. Because the inflation mechanism only allows 1% of the wallet to be donated, it actually requires many people to put their “inflation votes” and the attached XLM amount towards that project to meet the minimum token threshold.

This minimum threshold ensures that inflation pool funds are only being directed towards projects that have fairly broad community support, but it also means that projects with less attention may not be able to get funding this way. A financial platform called Lobstr has responded to this issue by essentially allowing users to participate in a collective inflation pool. By using Lobstr, community members can send their inflation money to any address, regardless of the amount of votes the project addressee has.

**How could initial development tools be funded in the Edgeware community?**

In thinking about how we can fund initial development tools for new protocols, like Edgeware, it’s important to consider the way that the structure of blockchain networks can be used to leverage developer talent and community-driven fundraising. For example, Polkadot’s “Initial Parachain Offering” idea, which is essentially a crowd-sourcing mechanism for parachains, makes it possible for innovative networks to develop in the Polkadot ecosystem with user support. Moreover, the introduction of parathreads to the infrastructure (chains with the same API that simply use a pay-as-you-go model), allow more development with significantly less funding. This is a good example of using the structure of a network to increase opportunity for innovation.

Let’s take the example of a dev tool like Polkascan to see how Edgeware could apply this concept of leveraging structure for sustaining development.

Polkascan is a 'block explorer' that supports not only Edgeware, but all Substrate-based chains. It is a tool that allows the public and developers to see data on the addresses, transactions, and block details for these chains in a readable, user-friendly format. The tool currently operates on a Web3 grant, but it’s worth considering how the networks that benefit from it can contribute to its development in the future.

Since many chains benefit from the tool, perhaps a platform could be created to allow users across chains can band together to donate their own funds to the project. An alternative could be to pull from treasuries and pool resources for a cross-chain grants program that allows more projects like Polkascan that have utility across protocols to get support from their beneficiary communities.

As the infrastructure for blockchain technology grows, it will be important to continually think about how the structure of the ecosystem can be used to sustain development. Does a VC funded grants program, or a grants program limited to one network, make sense in the blockchain space? Maybe instead, an inflation pool type mechanism could be useful, incentivizing the community to constantly think about development - but that mechanism would have to consider that it’s not always the projects with the most support that are the most innovative. Or perhaps a creative combination of crowd-funding and development incentives built-in to governance would be the best option.
