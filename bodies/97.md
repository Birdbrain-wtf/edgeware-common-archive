Testnet v0.9 is live, and you can run a node to join the network now.

```
git clone https://github.com/hicommonwealth/edgeware-node.git
./setup.sh
./target/release/edgeware --chain=chains/testnet-0.9.0.json
```

This release fixes the issues described in the [relaunch plan](https://commonwealth.im/#!/edgeware/proposal/discussion/52), including:

- Incorrect application of bonuses.
- Issue with validator rotations, which would cause block production to stall when sessions end.
- Issue with nodes stalling (reaching 100% CPU).

We've also started refreshing the documentation on the [Github wiki](https://github.com/hicommonwealth/edgeware-node/wiki). There's a new guide on how to [validate using the Polkadot UI](https://github.com/hicommonwealth/edgeware-node/wiki/Validating-on-Edgeware-%28UI%29). Look out for more guides coming soon!

### Validating on Mainnet

If you would like to be a mainnet validator, you will need to validate on the testnet and prove you have done so. You will also need to sign two messages, one using your testnet key, one using your mainnet key. The process is in the form below. We recommend looking at the form only after you have finished the process of running a testnet validator:
