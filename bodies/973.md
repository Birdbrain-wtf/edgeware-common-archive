# Solang Solidity Compiler

I'm the creator of [Solang](https://github.com/hyperledger-labs/solang), a solidity-to-wasm compiler. Using Solang, existing Solidity code can be compiled to wasm. Solang itself is written in rust, and uses llvm to generate optimized wasm code.

The project has practically all of the language covered, now it would be great to have people use it, and report any problems. As it is a new code base there are bound to be issues, like compiler warnings or error messages that don't make sense, or compatibility issues with Solidity.

Since Solang is a completely new code base under our control, we can new features to the language where it make sense. This can be both parachain specific (using chain extension, for example) or more generic features like new crypto functions, or better support for data structures. I'd love to hear some use cases!

[Solang](https://solang.readthedocs.io/) is currently supported by a [Web3 Foundation grant](https://github.com/w3f/General-Grants-Program/blob/master/grants/accepted_grant_applications.md#wave-8---fourth-quarter-2020) (the 2nd grant it received from the Web3 Foundation). To support future development, I am interested in exploring a feature grant.
