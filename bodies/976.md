Hey all, I'd like to propose my mixer to the Treasury as the first project for my organisation, Webb. We'd like to be the ecosystem partner that manages all things zero-knowledge, starting with a mixer and group pallets that could find utility with identity projects. We plan to make these tools general enough to support application developers building smart contracts so that they could create different types of groups and prove anonymously one's membership in them.

To that end, please leave feedback if any on the proposal. I will attach a roadmap for Webb this year of what I'd like to get done, some of which can hopefully be supported by the Edgeware Treasury.

As has been mentioned by remz, the core utility of a mixer is in the anonymity set. Webb wants to get a v1 mixer live so that we can start building out a great user experience for participating in the v1 mixer as well as begin building out an initial anonymity set. As I see it, Webb will continue to grow the anonymity set through optimisations throughout the year and future product launches that will bring liquidity to Edgeware in novel ways ([such as privacy bridges](https://commonwealth.im/edgeware/proposal/discussion/694-zkbridges) which I've written about).

In order to get us started with growing the anonymity set, we obviously have to get started deploying some tech! From there, we hope to explore new ways of improving the system that Ethereum is unable to, such as through fee-less txes using ZKPs as proxies for signatures. This would definitely be attractive work for us to sink our teeth into once we get this proposal and first set of milestones finished.
