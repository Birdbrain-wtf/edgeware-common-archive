Problem: Viewing a proposal in existing viewers does not connect it to a off-chain document/site/proposal text so that users can easily view context. 

Solution?

When submitting a proposal, the user can enter a URL linking to an off-chain source of context or explanation

Additional feature consideration:
On-chain data can contain problematic links, so Council should also be able to add a flag when rejecting or purging proposals that wipes the URL field's content from the on-chain storage. This charges councillors with content moderation, but this seems unavoidable.
