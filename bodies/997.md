# Overview
Last week or so I proposed the Tokyo upgrade release to the Edgeware democracy / council as an external proposal. There have been a few members of Commonwealth who have tested the release and some have added that they had issues replicating the release's hash on chain. This post is my process for handling the release.

# Srtool
It seems we can all replicate the `srtool` output using chevdor's script. First, I would recommend checking out the release:
cd edgeware-node
git checkout v3.2.0
Then, run the scripts needed to instantiate `srtool`. You will need docker in order to make this part work. For more information about `srtool` please refer to https://www.chevdor.com/project/2020/2020-srtool/.
export RUSTC_VERSION=nightly-2020-07-20; export PACKAGE=edgeware-runtime; alias srtool='docker run --rm -it -e PACKAGE=$PACKAGE -v $PWD:/build -v /tmp/cargo:/cargo-home chevdor/srtool:$RUSTC_VERSION'

srtool build edgeware-runtime
This should produce the same output as is shown on the Tokyo v3.2.0 release notes.

# Runtime proposal verification
After you've verified that your `srtool` output matches, we can proceed to testing how the actual runtime proposal will look on-chain. Note, the rust versions we use to verify these runtimes are different. For `srtool` it only works on an older `nightly-2020-07-20` rust version, whereas for the proposal, I used a much more recent `nightly` rust. That of:
active toolchain
----------------

nightly-x86_64-apple-darwin (default)
rustc 1.51.0-nightly (c0b64d97b 2021-01-28)
In order to download this, it's important not to use this date exactly. For whatever reason the nightly builds seem to be 1 day ahead of their pegs. So, in order to peg to this nightly version you should run:
rustup toolchain install nightly-2021-01-29
To instantiate a clean build, I recommend running
cargo clean
./scripts/build_only_wasm.sh edgeware-runtime
This should produce a binary called `edgeware_runtime.wasm` in the base directory of the `edgeware-node`.

## Creating the preimage
Once you have the runtime binary in hand, head to the PolkadotJS Apps UI and then to the Democracy page. Click on `Submit Preimage` and then add the runtime binary from the previous step for the `system.setCode` extrinsic like so.
